# Experience strategy

Warm off-white, dark green ink and restrained sage backgrounds make the website approachable. Self-hosted Manrope and supplied Digvation assets create consistency. The hero remains a full photograph with dark overlay and centered text. Repeated decorative gradients, fake dashboard proof and dense SaaS card walls are excluded.

Each page has a focused opening and a small number of distinct sections. Alternate text and useful visuals rather than stacking all ideas together. Services uses one selected need; Work features one case with real screenshots and filters the rest; product details explain use cases, flow and scope; About tells the 2022 story and future ambition; Contact pairs next steps with a clear form.

Real links and static HTML support direct access and discovery. Tabs support keyboard arrows, visible active state and one controlled panel. Mobile navigation uses a modal dialog, Escape, focus trapping and return to the opener. Process and discovery respond to scroll position; reveal animation never conceals passed content. Reduced-motion removes nonessential animation.

No automatic page transitions or scroll hijacking. Browser navigation loads the corresponding static document, preserving independent SEO and standard back/forward behavior. Errors are announced and entered form fields remain available after delivery failure.
